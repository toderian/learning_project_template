# PDFs

Temporary PDFs waiting for triage. Curated large PDFs may belong in
`04_areas/<area>/assets/attachments/<topic-path>/` with timestamp-prefixed
filenames and optional Git LFS.

PDFs can expose credentials, personal data, client data, account pages, or
private context. Keep sensitive originals in `.no-commit/` unless they are
redacted and intentionally safe to commit.
