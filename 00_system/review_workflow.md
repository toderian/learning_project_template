# Review Workflow

Use a light rhythm first. Add detail only when it helps.

## Minimum Cadence

- Daily: capture notes and journal briefly.
- Weekly: empty inbox and promote useful notes.

## Full Cadence

Daily:

- Write a quick journal note.
- Capture loose thoughts.
- Check due recall items.

Weekly:

- Triage inbox material.
- Update active projects.
- Promote useful notes.
- Create a limited number of flashcards.

Monthly:

- Review areas.
- Review important resources.
- Update maps of content.
- Archive stale projects.
- Check the external repo registry.

Quarterly:

- Prune memory cards.
- Archive old work.
- Decide whether any lab needs a separate repository.

Yearly:

- Synthesize major lessons.
- Archive completed cycles.
- Review long-term areas.
