# 11_templates

Reusable Markdown templates for the schema types in `00_system/schema.md`.

For new area and inbox notes, fill `created` and `updated` with full ISO 8601 local timestamps, for example `2026-06-09T14:30:12+03:00`. Empty date fields are allowed inside reusable templates.

Most topic-specific templates are intended for `04_areas/<area>/...` routes, not top-level global folders.
